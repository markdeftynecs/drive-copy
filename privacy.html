Privacy

Drive Copy uses drive.file access to upload selected files and read relevant file metadata for comparison and verification.

Files are stored in the authorised Google Drive account. Credentials and operational logs remain on the device running the utility. This website receives no credentials or file contents.

Google user data is not sold, used for advertising or model training, or shared except as needed to provide the requested Google Drive operations. Use of Google API data follows the Google API Services User Data Policy, including Limited Use requirements.

Access can be revoked in Google Account settings. Uploaded files remain until the user removes them through Drive. Contact details appear on Google's consent screen.

This site adds no tracking. GitHub hosts these pages under its privacy statement.
